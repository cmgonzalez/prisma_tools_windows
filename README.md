# Prisma Framework - Utilidades Windows

Colección de herramientas y utilidades para Windows utilizadas en el desarrollo con **Prisma Framework** para ZX Spectrum.

## Archivos incluidos

| Archivo | Descripción |
|---------|-------------|
| `z88dk-win32-2.3.zip` | Compilador Z88DK para desarrollo en C/ASM para ZX Spectrum |
| `ZEsarUX_windows-12.1.zip` | Emulador ZEsarUX - Emulador avanzado de ZX Spectrum |
| `fuse-1.6.0-win32.zip` | Emulador FUSE (Free Unix Spectrum Emulator) para Windows |
| `ZX-Paintbrush-2.6.4.zip` | Editor gráfico para crear sprites y gráficos para ZX Spectrum |
| `ZX-Paintbrush_2.6.4_Setup.zip` | Instalador de ZX-Paintbrush |
| `ZX-Font-3.3.zip` | Editor de fuentes para ZX Spectrum |
| `Tiled-1.11.2.zip` | Editor de mapas de tiles para diseño de niveles |
| `libresprite-development-windows-x86_64.zip` | Editor de pixel art y sprites (fork libre de Aseprite) |
| `ayfxedit.zip` | Editor de efectos de sonido para el chip AY-3-8912 |
| `Steve Turner SFX Editor.zip` | Editor de efectos de sonido de Steve Turner |
| `VT1.0-64.zip` | Vortex Tracker - Editor de música para chip AY |

## Uso

Descomprime las herramientas que necesites en tu directorio de trabajo.

## Notas

- Los archivos `.zip` grandes se manejan con **Git LFS**
- Estas herramientas son para uso con Windows
